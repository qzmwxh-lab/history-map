# 光之足迹新版

本目录与原站隔离。旧站继续使用仓库根目录，直到新版云端验收通过后再切换。

## 本地验证

使用 Node.js 24：`npm ci --ignore-scripts`、`npm run verify`、`npm run dev`。
`verify` 依次执行单元/数据库测试、Astro 类型检查和生产构建。仓库 CI 分开验证旧站和新版，互不依赖对方的安装目录。

Cloudflare Pages 预览部署：根目录 `next`，构建 `npm run build`，输出 `dist`。
前端仅配置 PUBLIC_SUPABASE_URL 和 PUBLIC_SUPABASE_KEY（publishable key）。
禁止把管理员密钥写入 PUBLIC_ 变量。
邀请接口还需要部署本目录 `functions/`（只上传 `dist` 不足以提供邀请服务）。
在 Pages 服务端环境配置 SUPABASE_URL、SUPABASE_SERVICE_ROLE_KEY 和 INVITE_REDIRECT_URL；管理员密钥必须使用秘密变量。
INVITE_REDIRECT_URL 应为该部署的 `/zh/login/` 完整 HTTPS 地址，并在 Supabase 登录回调白名单中精确允许；英文恢复密码另需 `/en/login/` 回调地址。
云端配置尚未完成，不能仅凭构建成功认定邀请或密码恢复可用。

公开档案页面允许搜索引擎收录；贡献者登录页保持 `noindex,nofollow`，并在 `robots.txt` 中禁止抓取。
